# 🏋️ GymCaps

Aplicativo web desenvolvido para monitoramento de treinos e interação entre usuários, permitindo o gerenciamento de rotinas e o compartilhamento de atividades.

---

## 🚀 Funcionalidades

- Cadastro e autenticação de usuários  
- Criação e gerenciamento de rotinas de treino  
- Feed de postagens entre usuários  
- Interface responsiva e adaptável para diferentes dispositivos  

---

## 🛠️ Tecnologias Utilizadas

- JavaScript  
- HTML5  
- CSS3  
- Git (versionamento de código)  

---

## 👨‍💻 Sobre o Projeto

O GymCaps foi desenvolvido como um projeto acadêmico em grupo com o objetivo de aplicar, na prática, conceitos de desenvolvimento web moderno.

Durante o desenvolvimento, atuei principalmente na construção do front-end da aplicação, sendo responsável pela criação de interfaces responsivas, organização de componentes e melhoria da experiência do usuário.

---

## 🎯 Objetivo

Este projeto teve como objetivo consolidar conhecimentos em desenvolvimento web, além de desenvolver habilidades em:

- Trabalho em equipe  
- Organização de código  
- Versionamento com Git  
- Desenvolvimento de interfaces modernas
